# AGENTS.md

This file provides guidance to agentic agents when working with code in this repository.

## Commands

```bash
pnpm install          # Install dependencies
pnpm start            # Dev server (alias: pnpm run dev)
pnpm run build        # Production build (clean → assets → eleventy → workbox SW)
pnpm run build:assets # Gulp only (JS + CSS)
pnpm run build:html   # Eleventy only
pnpm run svg          # Regenerate SVG sprite (src/icons/*.svg → src/includes/icons.svg)
pnpm run clean        # Delete dist/
```

No dedicated test runner — no unit tests in this project.

**Linting:**

```bash
npx eslint src/assets/scripts/**/*.js
npx stylelint src/assets/styles/**/*.css
npx prettier --check .
```

## Architecture

**Stack:** Eleventy 1.0 (SSG) + PostCSS + Gulp + Workbox (service worker)

**Build pipeline:**

1. Gulp processes JS (Browserify + Babel → `dist/assets/scripts/`) and CSS (PostCSS → `dist/assets/styles/`)
2. Eleventy builds HTML from `src/` → `dist/`
3. Workbox generates service worker in production

**Bilingual site (DE/EN):**

- `src/pages/de/` — German content (main language)
- `src/pages/en/` — English content
- `src/data/i18n.js` — loads UI strings from `src/data/translations/{de,en}/` (`books.json`, `glossary.json`, `movies.json`, `preface.json`, `toc.json`); exposed to templates as `i18n[locale]`
- `src/pages/de/de.json` / `src/pages/en/en.json` — Eleventy directory data files setting `locale`, `dir`, and the permalink scheme (DE is root-relative, EN is prefixed with `/en/`)
- `src/includes/language-switcher.njk` — language toggle UI; matches pages across languages on the `translationKey` front matter field
- Collections in `src/utils/collections.js` separate pages by `tags: ['book', 'german']` / `['book', 'english']`

**Templates:** Nunjucks (`.njk`) for layouts/includes, Markdown for content pages, both can use Nunjucks templating.

**Layouts chain:** `src/layouts/base.njk` → `default.njk` / `narrow.njk` / `fullsize.njk` → `page.njk`

**Key directories:**

- `src/utils/` — Eleventy config helpers: `filters.js`, `shortcodes.js`, `collections.js`, `minify-*.js`
- `src/assets/styles/` — PostCSS split into `base/`, `components/`, `layout/`, `critical/`; `critical/` CSS is compiled to `src/includes/critical/` and inlined
- `src/assets/scripts/` — `main.js` entry point with `modules/` and `embedded/`
- `src/data/site.js` — global site config (URL, title, author, language list, animation settings)
- `src/includes/` — Nunjucks partials; `icons.svg` is the SVG sprite (generated by Gulp, do not hand-edit)
- `src/icons/` — source SVG files for the sprite

**Environment-gated behavior (`ELEVENTY_ENV`):**

- `production`: lazy image plugin, HTML minification, CSS nano, no service worker in dev
- `development`: sourcemaps, no minification

**Shortcodes** (defined in `src/utils/shortcodes.js`): `{% product asin %}`, `{% youtube id %}`, `{% more text, url %}`, `{% download text, url %}`, `{% email text %}`, `{% duoColorImage light, dark %}`, `{% banner summary %}...{% endbanner %}`, `{% figure caption %}...{% endfigure %}`

**Deployed on Coolify**. Build output goes to `dist/`.
